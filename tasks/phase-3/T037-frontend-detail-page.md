# T-037: 简历详情页 + 候选人对比页

## 任务目标

新增两个核心页面：简历详情页和候选人对比页。

## 前置条件

- T-036 (公共组件 + api_client 增强) ✅

## 输出清单

| 文件 | 操作 | 内容 |
|------|------|------|
| `src/frontend/pages/6_简历详情.py` | 新增 | 简历详情页（~150行） |
| `src/frontend/pages/7_候选人对比.py` | 新增 | 候选人对比页（~120行） |

## 详细规格

### 6_简历详情.py

- **入口方式**: 通过 `st.query_params["id"]` 获取简历ID；也支持从 session_state
- **布局**: 三栏
  - 左栏: 个人信息卡片 + 统计指标
  - 中栏: 教育经历时间线 + 项目经历
  - 右栏: 技能标签云 + 操作按钮
- **数据来源**: `get_resume(resume_id)` → MongoDB
- **404 处理**: 简历不存在时显示错误 + 返回按钮
- **操作按钮**: 编辑（若role=admin）、删除（若role=admin）、返回搜索

### 7_候选人对比.py

- **入口方式**: session_state.compare_candidates 非空时可用
- **数据来源**: 遍历 compare_candidates，逐个调用 get_resume()
- **布局**: 横向并排表格
  - 每列一个候选人
  - 行：姓名、学历、经验、城市、匹配度、当前公司、当前职位、匹配技能、缺失技能
- **差异高亮**: 匹配技能绿色背景、缺失技能红色背景
- **空状态**: compare_candidates 为空时显示提示 + 跳转搜索页按钮
- **操作按钮**: 导出对比（调用 export_to_excel）

## 验收标准

| ID | Given | When | Then |
|----|-------|------|------|
| AC-037-01 | query参数 id=xxx | 打开详情页 | 显示完整简历信息 |
| AC-037-02 | 无效 id | 打开详情页 | 显示报错+返回按钮 |
| AC-037-03 | 已选2个候选人 | 打开对比页 | 并排展示2人信息 |
| AC-037-04 | 未选候选人 | 打开对比页 | 显示提示+跳转按钮 |
