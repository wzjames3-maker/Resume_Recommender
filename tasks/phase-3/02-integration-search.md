## 实现要求

### 测试链路
```
用户自然语言输入（如"找一个3年经验的Python开发"）
  → Intent 识别（提取：技能=Python, 经验=3年）
  → Hybrid Retrieval（Milvus 向量检索 + MongoDB 关键词检索）
  → Filter（按条件过滤候选人）
  → Rerank（按匹配度排序）
  → 返回推荐结果列表
```

### 测试用例设计
1. **基础搜索**: 简单查询 → 返回结果列表，结果按匹配度降序
2. **Intent 识别**: 验证从自然语言中正确提取结构化条件（技能、经验、地点等）
3. **Hybrid Retrieval**: 向量检索和关键词检索结果合并，不丢失应有结果
4. **Filter 生效**: 指定筛选条件后，返回结果均满足条件
5. **Rerank 排序**: 验证排序逻辑正确（匹配度高的排在前面）
6. **空结果**: 过于具体的查询返回空列表，不报错
7. **多条件组合**: 同时指定技能 + 经验 + 地点 → 结果同时满足所有条件

### 测试数据
1. 预置至少 20 条不同背景的候选人数据
2. 覆盖多种技能组合（Python/Java/Go、前端/后端/全栈）
3. 覆盖不同经验年限（1~10 年）
4. 覆盖不同城市（上海/北京/深圳/远程）
