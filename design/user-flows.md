# 用户流程（User Flows）

## UF-001: 智能候选人检索（recruitment.search）

```
1. HR 打开系统，进入聊天界面
2. HR 在输入框输入招聘需求（如"找5年Java工程师，杭州，985"）
3. 点击发送 / 按 Enter
4. 用户消息显示在右侧气泡
5. 系统显示"正在为您搜索候选人..."（Streaming 状态）
6. 系统逐步返回推荐结果：
   - 候选人卡片列表（姓名、匹配分、推荐理由、技能标签）
   - 缺失技能标签（灰色）
   - 综合评分（进度条/数值）
7. HR 可点击候选人卡片查看详情
8. HR 可继续输入追问（进入 UF-002）
```

**状态变化**：
| 步骤 | 状态 | 表现 |
|------|------|------|
| 3 | 输入中 | 输入框清空，消息出现在右侧 |
| 4-5 | 加载中 | 助手区域显示 typing indicator + "正在为您搜索候选人..." |
| 6 | 成功 | 候选人卡片列表渐入显示 |
| - | 空结果 | 显示"未找到符合条件的候选人，请尝试调整搜索条件" |
| - | 错误 | 显示"搜索遇到问题，请重试"+ 重试按钮 |

---

## UF-002: 多轮条件修正（recruitment.refine）

```
1. HR 在已有推荐结果基础上，输入修正条件（如"女生呢"）
2. 系统识别为 refine 意图
3. 系统显示"正在重新筛选..."
4. 系统返回更新后的推荐结果
5. 结果上方显示当前生效的筛选条件标签（如 #Java #杭州 #女 #985）
6. HR 可继续追问或点击条件标签移除某个条件
```

**状态变化**：
| 状态 | 表现 |
|------|------|
| 加载中 | 助手区域显示 typing indicator |
| 成功 | 更新后的候选人列表 + 筛选条件标签 |
| 空结果 | "在上次结果中无匹配，已扩大到全库检索"+ 新结果 |
| 无上文 | "请先描述您的招聘需求，如'找5年Java工程师'" |

---

## UF-003: 候选人详情查看（candidate.lookup）

```
1. HR 输入"第一个人是谁"或"看看张三的简历"
2. 系统从上一次推荐结果中定位候选人
3. 系统显示候选人详情卡片：
   - 基本信息（姓名、性别、年龄、城市）
   - 教育经历（学校、学历、专业、时间）
   - 工作经历（公司、职位、行业、时间）
   - 项目经历（项目名、角色、技术栈、描述）
   - 技能列表（分类展示）
4. PII 信息默认脱敏（手机、邮箱）
5. HR 可返回继续追问
```

**状态变化**：
| 状态 | 表现 |
|------|------|
| 加载中 | 显示"正在查询候选人信息..." |
| 成功 | 候选人详情卡片 |
| 未找到 | "未找到该候选人，请检查姓名或先进行搜索" |

---

## UF-004: 候选人对比（recruitment.compare）

```
1. HR 输入"对比前两个候选人"
2. 系统显示并排对比表格：
   - 技能对比（共同技能 / 各自独有技能）
   - 经验对比（年限、公司、职位）
   - 项目对比（项目数、亮点项目）
   - 教育对比（学历、学校）
3. 对比下方显示综合建议
```

---

## UF-005: 简历上传（resume.upload）

```
1. HR 点击侧边栏"上传简历"或输入"上传简历"
2. 系统显示文件上传区域（支持拖拽）
3. HR 选择文件（PDF / DOCX / JSON）
4. 系统显示解析进度（进度条 + 状态文字）
5. 解析完成后显示摘要（姓名、技能数、经历数）
6. 系统确认"简历已入库，可用于检索"
```

**状态变化**：
| 状态 | 表现 |
|------|------|
| 选择文件 | 文件选择器 + 支持格式提示 |
| 解析中 | 进度条 + "正在解析简历..." |
| 成功 | 绿色提示 + 解析摘要 |
| 格式错误 | 红色提示"仅支持 PDF/DOCX/JSON 格式" |
| 解析失败 | 黄色提示"解析失败，已保留原文"+ 建议 |

---

## UF-006: 新对话开始

```
1. HR 点击侧边栏"新建对话"
2. 聊天区域清空，显示欢迎消息
3. 欢迎消息包含系统能力简介 + 示例查询
```

---

## UF-007: 对话历史管理

```
1. HR 在侧边栏看到历史对话列表（按时间排序）
2. 点击某个历史对话，聊天区域加载该对话内容
3. HR 可删除某个历史对话
```

---

## UF-008: 登录流程

```
1. 用户访问系统，未登录时跳转到登录页
2. 输入用户名密码
3. 认证成功 → 进入聊天主界面
4. 认证失败 → 显示错误提示
```
