# 06-acceptance: Frontend v2.0 验收标准

## 6.1 简历详情页

| ID | Given | When | Then |
|----|-------|------|------|
| AC-010 | 已有简历ID | 访问详情页 | 显示完整个人信息、教育、工作、项目、技能 |
| AC-011 | 简历ID不存在 | 访问详情页 | 显示错误提示 + 返回按钮 |
| AC-012 | 从搜索结果点击 | 点击查看详情 | 跳转到详情页展示完整信息 |

## 6.2 高级搜索筛选

| ID | Given | When | Then |
|----|-------|------|------|
| AC-020 | 已登录 | 打开搜索页 | 侧边栏显示筛选器面板 |
| AC-021 | 选择城市=北京 | 发送搜索 | 搜索结果优先匹配北京候选人 |
| AC-022 | 选择学历=硕士 | 发送搜索 | 搜索结果仅含硕士及以上 |
| AC-023 | 选择经验3-5年 | 发送搜索 | 搜索结果仅含3-5年经验 |
| AC-024 | 勾选985 | 发送搜索 | 搜索结果仅含985院校毕业生 |
| AC-025 | 无任何筛选 | 发送搜索 | 返回综合推荐结果 |

## 6.3 候选人对比

| ID | Given | When | Then |
|----|-------|------|------|
| AC-030 | 有搜索结果 | 勾选3个候选人 | 对比列表包含3人 |
| AC-031 | 已选5个候选人 | 尝试选第6个 | 提示最多5人 |
| AC-032 | 已选2人 | 进入对比页 | 并排表格展示对比信息 |
| AC-033 | 对比页中 | 查看技能 | 匹配技能绿色、缺失技能红色 |

## 6.4 导出功能

| ID | Given | When | Then |
|----|-------|------|------|
| AC-040 | 有搜索结果 | 点击导出Excel | 下载 .xlsx 文件 |
| AC-041 | 搜索结果为空 | 点击导出Excel | 提示无数据可导出 |
| AC-042 | 有对比结果 | 点击导出对比 | 下载对比 .xlsx 文件 |
