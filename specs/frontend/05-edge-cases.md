# 05-edge-cases: Frontend 边界情况

## 5.1 认证相关

| ID | 场景 | 处理 |
|----|------|------|
| EC-001 | JWT 过期 | 清除 session_state → 跳转登录页 |
| EC-002 | API 不可达 | st.error("服务暂时不可用") |
| EC-003 | 浏览器 Tab 刷新 | session_state 丢失 → 重新登录 |
| EC-004 | 无权限访问管理页 | st.error + st.stop() |

## 5.2 搜索相关

| ID | 场景 | 处理 |
|----|------|------|
| EC-005 | Streaming 中断 | 显示已接收内容 + 重试按钮 |
| EC-006 | 搜索结果为空 | "未找到匹配候选人" + 建议放宽条件 |
| EC-007 | 筛选条件过严 | "筛选条件过严，建议放宽" |
| EC-008 | 对比列表为空进入对比页 | "请先在搜索结果中选择候选人" + 跳转 |

## 5.3 上传相关

| ID | 场景 | 处理 |
|----|------|------|
| EC-009 | 文件格式不支持 | st.error("仅支持 PDF/DOCX/JSON") |
| EC-010 | 文件过大 >20MB | st.error("文件大小超过限制") |
| EC-011 | 文件已存在（MD5重复） | 返回现有简历ID，提示已存在 |

## 5.4 数据相关

| ID | 场景 | 处理 |
|----|------|------|
| EC-012 | MongoDB 连接失败 | st.warning + 部分功能不可用 |
| EC-013 | 简历详情 ID 不存在 | "简历不存在或已删除" + 返回按钮 |
| EC-014 | 仪表盘无数据 | "暂无数据，请先上传简历" |
| EC-015 | 导出时无数据 | st.info("暂无数据可导出") |

## 5.5 操作相关

| ID | 场景 | 处理 |
|----|------|------|
| EC-016 | 重复点击导出按钮 | 按钮 disable 直到完成 |
| EC-017 | 删除操作确认 | 两步确认（删除 → 确认/取消） |
